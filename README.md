# myownersdesk.com

This repository is the source for myownersdesk.com, the website for The Owner's Desk (the construction services brand of Trailhead Standard LLC), published with GitHub Pages. It is deployed by a Codex push to a new GitHub repo named `myownersdesk` under the RylandPaul account, with the custom domain set by the CNAME file in this repo and DNS records managed at GoDaddy.
